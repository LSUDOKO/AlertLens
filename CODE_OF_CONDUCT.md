# Code of conduct

Be respectful. Criticise ideas and code, not people. Harassment and personal attacks are not welcome here.

Test only systems you are authorised to test. Don't post real credentials, personal data or live exploits in issues or pull requests.

To report a problem, use [private reporting](https://github.com/LSUDOKO/AlertLens/security/advisories/new). The maintainers may remove content or block accounts that break these rules.
